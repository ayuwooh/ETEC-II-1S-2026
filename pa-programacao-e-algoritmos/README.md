# PA - Programação e Algoritmos

Disciplina principal de lógica de programação com Python e Portugol (visualg).

## Conteúdo

- **Atividades:**
  - **01** — Algoritmos sequenciais (entrada, processamento, saída)
  - **02-03** — Estruturas de decisão (if/elif/else)
  - **04-06** — Estruturas de repetição (while, for)
  - **07** — Listas
- **Aulas:**
  - Exemplos de estruturas de repetição
  - Exercícios de decisão e repetição
- **Provas:**
  - Prova 01 — Lucro de loja de bolos
  - Prova 02 — Pesquisa de satisfação de plano de saúde
